# { title }

Это меню позволяет изменить отображение интерфейса и карты.

### <ChartArea size="16" class="inline-block" style="margin-bottom: 2px" />Профиль рельефа

Скрыть профиль высоты, чтобы освободить место для карты, либо отобразить его для изучения текущего выделения.

### <ListTree size="16" class="inline-block" style="margin-bottom: 2px" />Дерево файлов

Переключить отображение [списка файлов](../files-and-stats) в виде дерева.
Эта раскладка идеально подходит для управления большим количеством открытых файлов, так как она упорядочивает их в вертикальный список справа от карты.
Кроме того, древовидное представление файлов даёт Вам возможность исследовать [маршруты, отрезки и интересные точки](../gpx), содержащиеся в файлах через сворачивающиеся разделы.

### <Map size="16" class="inline-block" style="margin-bottom: 2px" />Переключиться на предыдущую основную карту

Изменить основную карту на ранее выбранную через [управление слоями карты](../map-controls).

### <Layers2 size="16" class="inline-block" style="margin-bottom: 2px" /> Переключение наслоений

Переключить видимость наслоений карты, выбранных через [управление слоями карты](../map-controls).

### <Coins size="16" class="inline-block" style="margin-bottom: 2px" />Метки расстояния

Переключить видимость меток расстояния на карте.
Они отображаются для текущего выделения, так же как и [профиль высоты](../files-and-stats).

### <Milestone size="16" class="inline-block" style="margin-bottom: 2px" />Стрелки направлений

Переключить отображение стрелок направлений на карте.

### <Box size="16" class="inline-block" style="margin-bottom: 2px" /> Переключить 3-мерный вид

Войти или выйти из 3-мерного режима отображения карты.

<DocsNote>

Чтобы управлять ориентацией и наклоном карты, вы также можете перетаскивать карту, удерживая <kbd>Ctrl</kbd>.

</DocsNote>

### <Maximize2 size="16" class="inline-block" style="margin-bottom: 2px" /> На весь экран

Вход или выход из полноэкранного режима.
Вы также можете нажать <kbd>F11</kbd> для переключения или <kbd>Escape</kbd> чтобы выйти.
