# { title }

Меню действий с файлами включает в себя список вполне понятных операций с файлами.

### <Plus size="16" class="inline-block" style="margin-bottom: 2px" /> Новый

Создание нового пустого файла.

### <FolderOpen size="16" class="inline-block" style="margin-bottom: 2px" /> Открыть...

Открыть файлы с вашего компьютера. 

<DocsNote>

Также Вы можете перетаскивать файлы прямо из файловой системы в окно.

</DocsNote>

### <Copy size="16" class="inline-block" style="margin-bottom: 2px" /> Создать копию

Создать копию выделенных файлов.

### <FileX size="16" class="inline-block" style="margin-bottom: 2px" />Удалить

Удаление выбранных файлов.

### <FileX size="16" class="inline-block" style="margin-bottom: 2px" />Удалить всё

Удаление всех файлов.

### <Download size="16" class="inline-block" style="margin-bottom: 2px" /> Выгрузить...

Открывает диалог для сохранения выделенных файлов на ваш компьютер.

### <Download size="16" class="inline-block" style="margin-bottom: 2px" /> Выгрузить все файлы...

Открывает окно выгрузки в котором можно сохранить все файлы на ваш компьютер.

<DocsNote type="warning">

Если загрузка не начинается после нажатия на кнопку загрузки, пожалуйста, проверьте настройки обозревателя и предоставьте необходимые разрешения на загрузку файлов с <b>gpx.studio</b>.

</DocsNote>
