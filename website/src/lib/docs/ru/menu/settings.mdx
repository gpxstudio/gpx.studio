### <Ruler size="16" class="inline-block" style="margin-bottom: 2px" />Единицы измерения расстояния

Изменение отображаемых единиц измерения расстояния.

### <Zap size="16" class="inline-block" style="margin-bottom: 2px" />Единицы измерения скорости

Изменение единиц измерения, используемых для отображения скорости.
Вы можете выбрать между отображением расстояния в час или минут, затраченных на преодоление расстояния, что больше подходит для беговых мероприятий.

### <Thermometer size="16" class="inline-block" style="margin-bottom: 2px" />Единицы температуры

Изменение единиц, используемых для отображения температуры.

### <Languages size="16" class="inline-block" style="margin-bottom: 2px" />Язык

Изменение языка, используемого в интерфейсе.

<DocsNote>

Вы можете внести свой вклад, добавив или улучшив переводы в нашем проекте <a href="https://crowdin.com/project/gpxstudio" target="_blank">Crowdin</a>.
Если Вы хотите начать перевод на новый язык, пожалуйста, <a href="#contact">свяжитесь с нами</a>.
Любая помощь очень ценится!

</DocsNote>

### <Sun size="16" class="inline-block" style="margin-bottom: 2px" />Тема оформления

Изменение используемой в интерфейсе темы оформления.

### <PersonStanding size="16" class="inline-block" style="margin-bottom: 2px" />Источник для уличного вида

Изменить источник, используемый для [отображения уличного вида](../map-controls).
По умолчанию используется <a href="https://www.mapillary.com" target="_blank">Mapillary</a>, но Вы также можете использовать <a href="https://www.google.com/streetview/" target="_blank">Уличный Вид Гугла</a>.
Узнайте больше о том, как использовать управление уличным видом в [разделе управления картой](../map-controls).

### <Layers size="16" class="inline-block" style="margin-bottom: 2px" /> Слои карты...

Открыть диалог, в котором можно включить или отключить слои карт, добавить пользовательские слои, изменить непрозрачность наслоений и многое другое.
Более подробную информацию о слоях карт можно найти в разделе [управление картой](../map-controls).
