# <Group size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

To use this tool, you need to [select](../files-and-stats) multiple files, [tracks, segments or routes](../gpx).

- Als je doel is om een enkel doorlopend spoor te maken vanuit je selectie, gebruik dan de **Verbind de sporen** optie en valideer.
- The second option can be used to create or manage files with multiple [tracks, segments or routes](../gpx).
  Merging files (or tracks) will result in a single file (or track) containing all tracks and routes (or segments) from the selection.

<DocsNote>

Geselecteerde items worden samengevoegd in de volgorde waarin ze worden weergegeven in de lijst met bestanden.
Herschik onderdelen door te slepen en te plakken indien nodig.

</DocsNote>
