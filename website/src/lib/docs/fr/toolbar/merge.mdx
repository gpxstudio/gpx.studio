# <Group size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

Pour utiliser cet outil, vous devez [sélectionner](../files-and-stats) plusieurs fichiers, [pistes, segments ou routes](../gpx).

- Si votre objectif est de créer une seule trace continue à partir de votre sélection, utilisez l'option **Connecter les traces** et validez.
- La deuxième option peut être utilisée pour créer ou gérer des fichiers avec plusieurs [pistes, segments ou routes](../gpx).
  Fusionner des fichiers (ou des pistes) résultera en un seul fichier (ou piste) contenant toutes les pistes et routes (ou tous les segments) de la sélection.

<DocsNote>

Les éléments sélectionnés sont fusionnés dans l'ordre dans lequel ils apparaissent dans la liste des fichiers.
Vous pouvez réordonner les éléments par glisser-déposer si besoin.

</DocsNote>
