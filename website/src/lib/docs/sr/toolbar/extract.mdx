# <Ungroup size="24" class="inline-block" style="margin-bottom: 5px" /> { title }

Ovaj alat vam omogućava da izdvojite [numere (ili segmente)](../gpx) iz datoteka (ili numera) koje sadrže više njih.

<div class="flex flex-row justify-center">
    <Extract class="text-foreground p-3 border rounded-md shadow-lg" />
</div>

Applying the tool to a file containing multiple [tracks or routes](../gpx) will create a new file for each of the tracks and routes it contains.
Slično tome, primena alata na numeru koja sadrži više segmenata će kreirati (u istoj datoteci) novu numeru za svaki od segmenata koje sadrži.

<DocsNote>

Prilikom izdvajanja tragova iz datoteke koja sadrži <a href="../gpx">tačke interesa</a>, alat će automatski dodeliti svaku tačku interesa trasi kojoj je najbliža.

</DocsNote>
